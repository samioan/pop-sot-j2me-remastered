# Prince of Persia: The Sands of Time decompilation and Windows port

Read README.md and sot/docs/ROADMAP.md first; sot/docs/NATIVE_ENGINE.md documents the translator,
runtime, widescreen and interpolation. The supported build is the Nokia Series 60 JAR (176x208,
MIDlet 1.1.0, SHA-256 40e7115a...). Reference approaches: ../sod-remastered (closest: same
pipeline), ../tes-travels-decomp, ../shadowkey-decomp.

- After completing and verifying a roadmap task, check it off in sot/docs/ROADMAP.md and keep its
  status/remaining lists accurate.
- Keep JARs, extracted/decoded assets, screenshots and tool binaries out of git.
- sot/decompiled is raw Vineflower output, sot/src the generated reference Java; both are written
  by tools/build_reference.py. Change sot/docs/names.map or the asserting entries in
  tools/build_reference.py, then regenerate. Do not edit generated trees.
- Rename only after inspecting call sites. Check decompiler artifacts against the original bytecode
  (tools/check_narrowing.py, tools/bytecode.py).
- The playable game is pop_sot.exe: sot/src translated to C++. sot/port/gen is generated by
  tools/gen_port.py from sot/src + tools/port_patches.py + tools/port_java (package pop2).
- Simulation is the original Game.run() iteration: Game.d() then paint, Game.H ms apart (80 in
  play; an iteration never takes less than 20 ms). The game clock (System.currentTimeMillis)
  follows the simulation. Presentation FPS is independent; interpolate recorded draw calls only.
- Widescreen: the view width (PortConfig.view) replaces 176 at the camera, tile-buffer and
  activation sites only; interface layouts stay 176 wide, centred, except screen-edge items.
  Verify both 176 and a wide width. Do not globally replace 176.
- Desktop changes go in tools/port_patches.py / tools/port_java as exact text with match counts.
  Add no field to the game's classes; every helper must return the original value at width 176
  with the original menus. python tools/check_engine.py compares that configuration with the
  original class files and must stay identical; run it (and --levels) after touching the
  translator, runtime, patches or port Java.
- The equivalence evidence compares state under fuzzed input, not pixels, and no full playthrough
  is recorded. Keep status statements accurate.
- Releases come only from a pushed tag vX.Y.Z (.github/workflows/release.yml); the launcher updates
  installs from those releases. Its package check expects PrinceOfPersiaSoT.exe at the top and
  bin/pop_sot.exe; keep build_dist.bat, check_dist.ps1 and launcher/game_identity.h in step.

Commands: .\setup.ps1 [-Jar PATH]; python tools/build_reference.py [--jar PATH];
python tools/check_narrowing.py; python tools/gen_port.py; .\sot\port\build.bat [Debug|Release];
.\sot\port\build_dist.bat [version]; python tools/check_engine.py [--levels]. CI builds without any
game data.
